# python-labs

Premiers scripts Python.

## Lab 1 : affichage et saisie

- `bonjour.py` : affiche « Bonjour Python »
- `bonjour_input.py` : demande un prénom et l'affiche avec sa longueur

## Lab 2 : variables et types

- `lab2_variables.py` : types de base, `type()`, réaffectation, mutabilité, conversions
- `lab2_conversion_input.py` : `input()` renvoie une chaîne, conversion avec `int()` et `try/except`

### Exercices

- `calc.py` : mini-calculatrice (+, -, *, /) avec gestion des erreurs
- `conversion.py` : conversion Celsius / Fahrenheit / Kelvin
- `texte.py` : analyse de texte (longueur, majuscules, inversion, palindrome)

## Utilisation

Windows : `python nom_du_fichier.py` (ou `py nom_du_fichier.py`)

macOS / Linux : `python3 nom_du_fichier.py`
